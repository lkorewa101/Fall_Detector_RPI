# 모바일 앱 사용방법

## APK

- `00_hospital_fall_dashboard.apk`

## 설치

1. APK 파일을 Android 휴대폰으로 옮깁니다.
2. 휴대폰에서 APK를 실행합니다.
3. 설치 차단 메시지가 나오면 해당 파일 관리자/브라우저의 "알 수 없는 앱 설치"를 허용합니다.

## 외부 접속

PC에서 프로젝트 루트의 `RUN_PUBLIC_DASHBOARD.bat`을 실행하면 Cloudflare Tunnel이 열립니다.

터미널에 표시되는 주소를 앱에 입력합니다.

```text
https://xxxx.trycloudflare.com
```

앱은 입력한 주소를 저장하므로 다음 실행부터는 자동으로 같은 대시보드를 엽니다.

## 주의

터널 주소를 아는 사람은 관제 화면과 블랙박스 목록에 접근할 수 있습니다. 전시 현장에서만 공유하고, 공개 배포가 필요하면 비밀번호 보호를 추가하는 것을 권장합니다.
